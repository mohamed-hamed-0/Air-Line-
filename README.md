# Airline Baggage Weight Calculator ✈️🧳

A C# Console Application designed to calculate allowable baggage weight and any extra fees based on the passenger's ticket class for "Saudi Arab Line". 

هذا المشروع عبارة عن تطبيق (Console) مبرمج بلغة C# لحساب الوزن المسموح به لحقائب المسافرين والتكلفة الإضافية للوزن الزائد بناءً على درجة التذكرة.

## 🚀 Features (المميزات)
* **Multi-Passenger Support:** Process baggage details for multiple passengers in a single session.
* **Class-Based Limits:** Automatically determines the allowed weight based on ticket degrees (A: 30kg, B: 20kg, C: 10kg).
* **Cost Calculation:** Calculates extra baggage fees dynamically (10 SAR per each extra kilogram).
* **OOP Architecture:** Built using Object-Oriented Programming principles for clean and maintainable code.

## 🛠️ Technologies Used (التقنيات المستخدمة)
* **Language:** C#
* **Framework:** .NET (Console Application)
* **Concepts:** Object-Oriented Programming (OOP), Control Flow, I/O Operations.
